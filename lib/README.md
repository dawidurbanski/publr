# Publr libraries

This directory contains generated, first-party libraries maintained in other
Publr repositories and checked into CMS for offline, reproducible builds.

Do not edit generated artifacts here directly. Regenerate them in their source
repository, then update the checked-in CMS copy. Third-party dependencies belong
in `vendor/`; their license and provenance files live beside each library,
with a consolidated inventory in `THIRD_PARTY_NOTICES.md`.
